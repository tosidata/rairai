# Create a successful MCP tool response

Create a successful MCP tool response

## Usage

``` r
tool_value_response(..., auto_unbox = TRUE)
```

## Arguments

- ...:

  Fields to include in the JSON object.

- auto_unbox:

  Passed to
  [`jsonlite::toJSON()`](https://jeroen.r-universe.dev/jsonlite/reference/fromJSON.html).

## Value

JSON text for successful MCP tool content.
